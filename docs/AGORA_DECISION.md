# 차별화 검토와 이번 데모의 선택

2026-11-15 아고라에서 ‘기존 AI 장소 추천 대신 내키면을 굳이 켤 순간’을 두 라운드로 검토했습니다. 이 문서는 회의 export와 검증 기록을 대조해 작성한 공개용 요약입니다. 내부 대화 원문·실행 로그·데이터베이스는 저장소에 포함하지 않습니다.

권고는 **C: 마음을 구체적인 체험으로 연결하기**를 핵심으로, **E: 조건을 통과한 장면 중 한 장 뽑기**를 보조로 삼는 것입니다. 감성 키워드나 뽑기 자체가 독점적인 기술이라는 주장은 없습니다. 실제 재방문, 선택 부담 감소, 마케팅 효과는 아직 검증하지 않았습니다.

## 누가 어떤 입장을 냈는가

| 모델·역할 | 1라운드 핵심 / 보조 | 2라운드 핵심 / 보조 | 유지·변경 이유 |
| --- | --- | --- | --- |
| Claude Opus 5.5 medium · 기획 | C 마음→장면 / D 기간 테마 | C / E 한 장 뽑기 | 테마의 출처·만료·갱신 담당이 없어서 D를 이번 데모의 보조에서 제외. 활동이 달라지는 화면과 명시적 내비 확인을 우선 |
| GPT-6 Astra · 개발 | D 기간 테마 / E 함께 고르기 | C / E | 시점 있는 테마의 가치를 입증할 자료가 부족해 변경. D가 장기적으로 열위라는 뜻은 아니며, 새 뽑기 조작의 제한 차단을 재검증해야 한다고 지적 |
| Claude Sonnet 5.5 medium · 디자인 | C / E | C / E 유지 | 같은 장소라도 활동·소요시간·도착 후 행동의 차이가 보여야 함. 형용사 교체와 추가 설문·동행 초대 부담을 경계 |
| Gemini 4 Argon medium · 리스크 | C / E | C / E 유지 | 모방 가능성과 제출 일정·회귀 위험을 강조. 기존 카드 구조의 최소 변경과 제한 모드 검증 권고 |
| GPT-6.1 Sol · 중재·서기 | 후보와 평가 기준 정리 | 실제 의견 분포·이견 정리 | 전문가 표에 추가하지 않음. 중재자와 서기는 같은 모델이며 별도 독립 평가자 2명이 아님 |

검증 기록의 모델 식별자는 각각 `claude-opus-5-5-medium`, `gpt-6-astra`, `claude-sonnet-5-5-medium`, `gemini-4-argon-medium`, `gpt-6.1-sol`입니다. Codex 모델명은 요청값, Antigravity 모델명은 CLI 보고값입니다.

1라운드에서 전문가 4명의 핵심 의견은 C 3명·D 1명이었고, 2라운드에는 4명 모두 C/E 권고로 수렴했습니다. 서로의 발언을 읽고 반박한 역할별 토론이므로 **‘5개 모델의 독립 투표’나 고객 조사 결과가 아닙니다.** 원본 회의의 사용자 결정 상태는 `pending`이며, 이 문서는 그 상태를 변경하거나 사용자 승인이 있었다고 표시하지 않습니다.

## 가장 강한 반론과 남은 이견

다른 AI도 기분을 입력받고 활동을 제안할 수 있습니다. 고정 장소 세 곳에 활동 문구만 붙이는 수준이면 사용자의 ‘식상하다’는 지적을 해결하지 못할 수 있습니다. 한 장 뽑기도 후보가 빈약하면 잠깐의 장식에 그치며 재방문을 만들지 못합니다. 따라서 체험 이해·선택 부담·정보 오해를 기존 장소 목록과 비교해야 합니다. [제품 비교 시험](PRODUCT.md)

기획은 활동 화면의 최소 추가를 제안했고, 개발·디자인·리스크는 기존 카드 활용과 새 제한 조작 검증을 더 강조했습니다. C/E 방향에는 수렴했지만 화면 확장 범위까지 완전히 합의한 것은 아닙니다. 회의의 최소 권고는 두 프리셋 비교였으며, 최종 구현은 네 가지 명시적 마음 프리셋과 로컬 문구 해석·기존 카드·선택형 뽑기를 포함합니다. 구현된 범위와 실행 검증은 [테스트 기록](TEST_PLAN.md)을 따릅니다.

## 후보와 이번 범위

| 후보 | 이번 데모 | 후속 조건·가치 가설 |
| --- | --- | --- |
| A 현재 필요·시간·차량 조건으로 후보 축소 | 시간·복귀·활동 조건을 체험 제안의 기반으로 유지 | 목적지·업종이 이미 정해졌다면 기존 지도로 충분할 수 있음 |
| B 눈치게임: 붐빔을 피하는 경험 | 실제 혼잡·대기·‘승리’ 표시는 제외 | 정확한 지역·시각의 데이터, 권역 혼잡과 개별 장소 대기의 구분 확보 후 재검토 |
| C 마음→구체적인 체험 | 핵심. 마음별 순서·활동·이유를 다르게 제안 | 활동 적합성 검수와 선택 가치·재방문 효과 검증 필요 |
| D 기간 테마·현재 트렌드·지역 이벤트 | 실시간 트렌드·현재 행사 표시는 제외 | 출처·유효기간·갱신 담당·검수 비용이 확보되면 주간 테마 등으로 재검토 |
| E 함께 고르는 놀이·뜻밖의 발견 | 시간·활동 조건을 통과한 후보에서 선택형 한 장 뽑기. 자동 내비 실행 없음 | 재미·결정 부담·반복 사용 효과 검증. 동행 초대나 필수 설문은 없음 |
| 도착 후 미션·기념카드 | 완료 판정·수집·보상 기능 없음 | 이번 범위를 벗어남. 카드의 활동 제안은 미션 완료 기능이 아님 |

B와 D를 나쁜 아이디어로 결론 내린 것은 아닙니다. 이번 데이터와 남은 구현·검증 시간에서 신뢰할 수 있게 보여줄 수 있는 범위를 좁혔습니다.

## 혼잡 데이터 판단의 근거

회의에 제출된 2026-11-15 21:39 KST 실측 메모에서 뚝섬한강공원·서울숲공원·건대입구역을 각각 요청했지만, 세 샘플 응답 모두 광화문·덕수궁, ‘여유’, 기준 시각 21:10을 반환했습니다. 이 결과를 서울숲이나 뚝섬 후보의 실제 혼잡 정보로 붙이면 지역이 틀린 안내가 됩니다. 서기는 이 보고를 토론 근거로 사용했으며 API를 독립 재실행한 것은 아닙니다.

유효한 키나 다른 데이터로 지역별 정보를 확인할 가능성은 후속으로 남깁니다. 지역 데이터가 맞더라도 개별 카페 대기나 주차 빈자리를 보장하지 않으므로, 이번 데모는 샘플과 미확인 상태를 유지합니다.

## 표시 문구의 후속 검토

초기 회의의 기능 설명과 최종 화면 문구는 구분합니다. 사용자의 문구 지적 후 Argon이 한국어 제품 카피를 두 차례 검토했습니다. 현재 화면은 `추천 장소 보기`, `하나만 바로 추천받기`, `다른 곳 보기`, `자세히 보기`로 표시하며 초기의 카드·뽑기 은유를 사용하지 않습니다. 추천 제목도 구체적인 행동형 표현으로 바꿨습니다. 이 변경은 기능 검토를 고객 카피 품질의 근거로 삼지 않기 위한 교정입니다.
