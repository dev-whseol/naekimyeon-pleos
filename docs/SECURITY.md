# 보안과 개인정보

0.3은 명시적인 위치 사용 선택 뒤 **앱이 전경에 있을 때만** 위치를 취득한다. 실제 위치 기반 추천은 검토한 공원 자료와 기기 안에서 비교한다. 계정·자체 서버·분석 SDK·인터넷 권한·백그라운드 위치 권한은 없다. 이는 보안 인증이나 실차 검증 완료를 의미하지 않는다.

## 위치와 입력

‘앱을 열 때 내 위치 사용’은 기본 OFF인 선택 설정이다. 정차 중 사용자가 직접 켜고 위치 권한이 있을 때만 `use_on_launch` Boolean 하나를 저장한다. 이후 실행에서도 현재 권한을 다시 확인하며, 샘플 선택·OFF·권한 철회 시 이 설정을 끄고 위치 취득을 중단한다.

- 최초 위치 사용과 Android 권한 팝업은 정차 중 명시적인 사용자 선택으로만 시작한다. 대략적 위치도 허용한다.
- 이미 허용한 전경 세션은 D에서도 센서 위치를 갱신할 수 있다. 권한 팝업을 주행 중 띄우지 않는다. 앱 비활성·샘플 모드 선택·세션 종료 시 취득을 중단한다.
- 위치는 메모리에만 둔다. 120초를 초과한 위치·5 km를 넘는 오차·유효하지 않은 값은 추천 근거로 쓰지 않는다. 권한이 철회된 후 도착한 콜백과 취소된 요청을 폐기한다.
- 좌표·이동 이력·마음 원문은 저장 상태, 파일, 로그, 분석, Gleo 응답에 넣지 않는다. 감정 진단과 성향 추론을 하지 않는다.
- Gleo는 명시적으로 고른 데이터 모드의 실제 화면 결과만 응답한다. 위치나 적합한 후보가 없으면 확인을 요청하며 샘플로 자동 대체하지 않는다. Gleo 요청 자체는 내비를 시작하지 않는다.

## 내비와 화면

CarUxRestrictions 상태를 사용한다. 상태 미확인에서는 내비 변경을 막고, 알려진 D에서는 한 곳 요약·다른 곳 보기·목적지가 명시된 안내만 제공한다. 정차 중 상세 확인에서 보여 준 조건·후보·위치·모드가 바뀌면 이전 확인을 무효화한다. Activity에서도 안전 상태와 실제 장소에 필요한 위치 유효성을 다시 검사한다.

장소 대표 좌표는 차량 진입점으로 검증한 좌표가 아니다. 출처·확인 날짜와 한계를 설명하고 사용자가 내비에서 경로를 확인하도록 한다. 위치 오차, API 장애, 미확인 영업·주차 정보를 정상 확인 결과로 바꾸지 않는다.

## 공개에서 제외하는 정보

개인 연락처·신청서·동의서·서명, API 키·비밀번호·토큰·쿠키, keystore, 개인 위치·차량 식별자, 원본 로그·회의 데이터베이스·로컬 설정은 공개하지 않는다. `.gitignore`만 믿지 않고 추적 파일과 최종 산출물을 점검한다. 출품자 이름이 있는 제출 APK 파일명은 별도로 허용된 제출 식별자다.

서명 키는 저장소 밖에 보관하고 `keystore.properties`는 무시한다. 바이너리에 포함한 비밀값은 추출할 수 있으므로 서버 키를 BuildConfig·assets·난독화로 숨기지 않는다. 향후 외부 API 연동은 키의 권한·호스트·쿼터·TTL을 제한하는 서버 경계에서 설계한다.

## 플랫폼 경계

`allowBackup=false`, 데이터 백업·기기 이전 제외, `usesCleartextTraffic=false`를 유지한다. Launcher/Gleo Activity는 공개되어 있으므로 요청 길이·형식·범위를 검증한다. 필요한 내비 및 전경 위치 권한만 선언한다. 위치 소스와 Activity는 종료 시 콜백·타이머·연결을 해제한다.

Android LocationManager 동작과 Pleos FusedLocation SDK 지원은 구분한다. Pleos SDK 문서는 Android 위치 권한 동작을 별도로 보장하지 않으므로 이번 에뮬레이터 결과를 모든 실제 차량 지원으로 확장하지 않는다. [Pleos FusedLocation 소개](https://document.pleos.ai/en/docs/pleos-only/connect-sdk-pleos/FusedLocation/intro)
