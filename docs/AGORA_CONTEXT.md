# 원안과 회의 컨텍스트 복구

내키면의 범위는 **목적지를 정하지 않은 상태에서 현재 상황·기분·동행 조건에 맞는 외출·여행을 고르는 차량용 앱**입니다. 시간 미정·무제한·마감이 있는 경우를 구분합니다. 사용자가 거절한 픽업 조율, 동행의 분리 외출·재합류, 다른 사업으로의 전환을 현재 제품 방향으로 채택하지 않습니다. 모델의 권고는 사용자 승인과 다릅니다.

## 확인한 문제

기존 아고라의 컨텍스트 조립은 직접 부모의 짧은 보고서와 최근 사용자 요청에 의존했습니다. 일부 새 회의는 `parentId=null`로 생성되어 앞선 회의의 제약을 잇지 않았고, 별도 `directLocalCli` 호출은 `buildContext`도 거치지 않았습니다. 따라서 답변을 독립적으로 생성하는 과정에서 사용자 원안과 거절 이력까지 빠질 수 있었습니다. 모든 모델의 기억 능력에 문제가 있다는 뜻은 아닙니다.

## 적용한 수정과 확인

- 로컬 아고라에 최대 12,000자의 `projectBrief`를 추가했습니다. 생성 시 고정하며, 생략하면 명시적 부모의 같은 회의군에서 상속합니다. 빈 문자열은 의도적인 초기화이며 `null`은 거절합니다.
- 기준문서는 대화 요약과 별도로 전체를 전달합니다. 조상 회의의 사용자 제약은 제한된 길이로 함께 전달하고, 다른 회의군이나 최근 회의를 임의로 섞지 않습니다.
- 프로젝트 호출 도구에 원안·거절 이력을 담은 공통 기준문서와 부모 연결 검사를 적용했습니다. 독립 모델 호출에도 동일한 기준을 전달합니다.
- 로컬 아고라 테스트 **42개와 빌드가 통과**했습니다. 서버 재시작 후 생성한 후속 회의에서 **1,912자 기준문서가 완전히 일치**했고 실제 전달 컨텍스트는 **12,541자**였습니다. 호출 전 스냅샷·해시를 로컬 검증 기록에 보존했습니다.

과거 회의 발언·보고서·승인 상태는 수정하지 않았습니다. 이 수정은 외부 채팅 전체를 자동으로 기억하는 기능이 아닙니다. 이후에도 새 사용자 정정은 기준문서와 다음 호출에 명시적으로 반영해야 합니다. 내부 로그·회의 데이터베이스·개인 자료는 이 공개 저장소에 포함하지 않습니다.

## 앱에 반영할 범위

0.2는 확인된 주행 제한 상태에서 한 곳 요약과 별도의 목적지 확인을 제공하고, 정차 시 전체 비교 화면을 사용합니다. 실제 에뮬레이터 D 화면과 주행 패널 시험을 확인했습니다. 키보드·사진·긴 목록은 주행용 화면에서 제외하고, 상태를 알 수 없으면 내비 변경을 허용하지 않습니다. 실제 활성 제한과 콘텐츠 길이·수량을 적용합니다. [테스트 기록](TEST_PLAN.md)에서 확인 범위를 구분합니다. DO 선언은 공식 심사나 Gleo 음성 승인을 뜻하지 않습니다.
