# 시연 자료와 이미지 출처

앱의 강변·카페 이미지는 이 프로젝트 기획 과정에서 생성한 AI 예시 이미지입니다. 실제 추천 장소 사진, 현장 촬영, 장소의 현재 상태를 나타내지 않습니다. 화면에 같은 안내를 표시합니다. 카메라 권한이나 차량 카메라는 사용하지 않습니다.

- `app/src/main/res/drawable-nodpi/riverside_concept.webp`: 강변 휴식의 분위기를 표현한 예시
- `app/src/main/res/drawable-nodpi/cafe_concept.webp`: 비 오는 날 창가 휴식의 분위기를 표현한 예시
- 앱 아이콘과 화면 기호: 프로젝트의 벡터·Canvas 코드로 작성
- `demo/screenshots`: 실제 Pleos Connect Emulator 2.1.0에서 실행한 release 앱 또는 그 녹화에서 추출한 화면
- `demo/naekimyeon-demo.mp4`: 실제 실행 녹화의 대기 구간을 편집한 시연본

외부 음악, 실제 인물의 목소리 복제, 실제 방문 인증, Gleo가 직접 말한 것처럼 보이는 음성 연출은 포함하지 않습니다. 실시간 정보와 실제 차량 주행 검증도 영상만으로 주장하지 않습니다. 기존 영상의 0.1 화면과 0.2 주행용 화면의 검증 범위는 테스트 기록에서 구분합니다.
