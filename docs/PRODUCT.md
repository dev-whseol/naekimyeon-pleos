# 내키면이 제안하는 경험

**계획 없어도, 마음 가는 곳으로.** 내키면은 목적지가 아직 없는 순간, 기분과 하고 싶은 일에 맞는 장소·활동을 제안하고 사용자의 확인을 거쳐 내비로 이어 주는 차량용 앱입니다. 시간은 선택 조건이며, 시간이 미정이거나 제한이 없어도 시작할 수 있습니다. 고르기 어렵다면 ‘하나만 바로 추천받기’로 조건에 맞는 장소 하나를 확인할 수 있습니다.

제품의 기준은 사용자가 제시한 즉흥 외출·여행 원안입니다. 혼자 생긴 여유, 둘이 계획 없이 나선 시간, 가족 행사 전후, 여행 중 자유시간에 갈 곳을 고르는 흐름을 개선합니다. 동행의 분리 외출·재합류나 픽업 조율로 목적을 바꾸지 않습니다. [원안과 컨텍스트 복구](AGORA_CONTEXT.md)

감정 표현으로 장소를 찾는 방식 자체의 독창성을 주장하지 않습니다. 이 제품에서 검증할 가치는 **마음 표현 → 구체적인 체험 → 이동·복귀 조건 확인 → 사용자가 승인한 내비 인계**가 한 흐름으로 이어져, 목적지를 정하기 전에 해야 하는 검색과 비교를 줄이는지입니다. 0.3은 현재 위치와 검토한 서울·과천 공원 세 곳을 연결하며, 기존 샘플은 명시적으로 선택해서 봅니다. 실제 효과가 입증된 서비스는 아닙니다. [현재 자료와 한계](DATA_SOURCES.md)

## 사용 장면

아래는 실제 구현한 네 가지 마음 프리셋과, 시간·활동 조건에 걸리지 않을 때 먼저 제안하는 예시입니다. 카드에는 장소의 업종보다 **무엇을 해 볼지**와 **왜 지금 선택한 마음에 맞는지**를 먼저 보여줍니다. 자유 입력은 120자 이내의 알려진 표현을 로컬 규칙으로 연결합니다.

| 순간 | 제안할 경험의 형태 | 마음에 주는 가치 가설 | 실제 선택에 필요한 정보 |
| --- | --- | --- | --- |
| ‘머리 좀 비우고 싶어’ | 강변 후보의 ‘강변 벤치에 앉아 하늘 보기’: 벤치에서 10분 하늘 바라보기 | 할 일을 더 찾지 않아도 작은 쉼을 상상할 수 있음 | 가는 시간, 확보할 체류 시간, 돌아올 기준 |
| ‘둘이 가볍게 다녀오고 싶어’ | 나무 쉼터 후보의 ‘마음에 드는 나무 골라 소개하기’: 각자 마음에 드는 나무를 골라 소개하기 | 업종 검색 대신 함께 할 구체적 행동을 고를 수 있음 | 활동 조건, 주차 확인 범위, 이동 부담 |
| ‘색다른 곳에 가보고 싶어’ | 나무 쉼터 후보의 ‘눈에 띄는 모양이나 색 찾아보기’: 처음 눈에 들어온 모양·색을 사진으로 남기기 | 익숙한 장소에서도 보는 방식을 바꾸는 재미의 가능성 | 샘플 표시, 다른 후보 확인, 별도의 출발 승인 |
| ‘오늘은 편하게 쉬고 싶어’ | 카페 후보의 ‘카페에 앉아 음료 마시며 쉬기’: 한자리에 앉아 음료 마시며 쉬기 | 무언가를 해내야 한다는 부담 없이 고를 수 있음 | 실내 여부·체류 시간. 실제 조용함·영업·빈자리는 보장하지 않음 |

45분처럼 시간이 정해진 경우에도 장소를 고르기 전에 긴 설문을 요구하지 않습니다. 같은 출발점으로 돌아오겠다고 선택했을 때만 왕복·접근·여유 시간을 빼서 머물 시간을 계산합니다. 시간이 미정이면 미정으로, 제한이 없으면 무제한으로 유지합니다. 주차장이 있는 예시는 빈자리·요금·영업 확인과 구분합니다.

‘하나만 바로 추천받기’는 이미 시간·활동 조건을 통과한 후보 중 하나를 보여줍니다. ‘다른 곳 보기’를 누르면 두 곳 이상인 경우 직전 장소를 피하고, 한 곳뿐이면 선택 가능한 곳이 하나임을 안내합니다. 추천이나 다른 후보 확인은 경로를 바꾸지 않으며 상세 화면에서 목적지를 확인한 뒤 내비 인계를 별도로 승인합니다. 활동 문구는 방문 제안이고 완료 판정·보상·수집 기능은 없습니다. [아고라의 검토와 문구 교정](AGORA_DECISION.md)

## 이름 바꾸기를 넘어서는 기준

- 마음을 바꾸면 적합한 체험과 추천 순서가 실제로 달라져야 합니다. 업종 카드의 제목만 바뀌는 것은 충분하지 않습니다.
- 카드의 행동은 사용자가 도착해서 무엇을 할지 설명할 수 있을 만큼 구체적이어야 합니다. 예를 들어 ‘감성 공간’보다 ‘카페에서 음료를 마시며 이야기하기’가 검증하기 쉽습니다.
- 이유는 사용자가 고른 표현과 연결되어야 합니다. 사용자의 심리 상태를 진단하거나 모든 사람에게 맞는다고 단정하지 않습니다.
- 추천을 보기 전 필수 질문과 화면 수를 늘리지 않습니다. 마음을 아직 고르지 않거나, 모르는 표현을 입력해도 선택 가능한 짧은 대안을 보여줍니다.
- 어떤 감성 표현도 시간·복귀·주행 제한을 무시하는 예외가 되지 않습니다. 실제 내비 변경은 별도의 사용자 확인을 거칩니다.

## 현재 검증한 기반과 남은 범위

0.2는 실제 Pleos Connect 2.1.0의 D 상태에서 한 곳 요약·명시적 안내 확인을 표시하고 정차 시 전체 비교를 복원합니다. 활성 제한·문자 길이·후보 수를 적용하고 미확인 상태는 제한합니다. JVM 38개와 기기 32개가 나누어 실행되어 총70개 통과했습니다. 제품 재미·재방문 효과·공식 심사 승인을 뜻하지 않습니다. [실행 기록](TEST_PLAN.md)

0.3은 전경 위치를 사용하고 실제 공원 자료의 출처·대표 좌표·주소·직선거리를 보여 줍니다. 실제 이동 시간·교통·날씨·혼잡·영업·주차 빈자리는 조회하지 않습니다. 샘플 모드의 AI 예시 이미지는 실제 방문 장소의 사진이 아니며 실제 장소 모드에는 안내 그림을 사용합니다. 로컬 문구 해석은 지원하는 표현을 규칙으로 연결하는 방식이며 자유로운 대화를 이해하는 범용 AI나 개인 감정 분석 기능이 아닙니다. 인식하지 못한 표현을 임의로 해석해 확신하는 대신 마음 선택을 제안합니다.

0.3의 JVM 60개·기기 45개와 실제 에뮬레이터 D 추가 시험은 [개선 검증](UPGRADE_TESTS.md)에 기록합니다. 장소가 모두 공원이어서 활동 문구가 반복되는 한계가 남아 있습니다. 장소별 구체적 활동, 실내 후보, 동행 상황에 따른 선택의 차이를 확대하고 검증해야 합니다. 위치 연동 성공을 재미·차별성·재방문 효과의 검증으로 대신하지 않습니다.

Gleo의 Android action·파서·응답 구현과 실제 음성 서비스 승인은 구분합니다. 공식 스키마 승인과 실시간 음성 호출은 확인하지 않았습니다. 감정적 편안함이나 기분 개선은 제품 가치 가설이며 심리 치료·의료 효과를 의미하지 않습니다.

## 비교 시험

작은 파일럿에서 같은 사람이 동일한 장소 데이터와 이동 조건으로 두 흐름을 사용하게 합니다. 하나는 업종·장소 중심 목록, 다른 하나는 마음·체험 중심 흐름입니다. 순서를 번갈아 배정하고 같은 장소를 먼저 본 학습 효과를 기록합니다. 외부 서비스보다 우수하다는 결론을 내리기 전에 데이터·후보 수·화면 성능 차이를 통제합니다.

| 확인할 점 | 측정 방법 |
| --- | --- |
| 고르기 쉬운가 | 수용할 만한 후보를 정할 때까지 걸린 시간, 선택·되돌리기 횟수, 중도 포기 |
| 체험이 구체적인가 | 사용자가 ‘그곳에서 무엇을 할지’를 자기 말로 설명할 수 있는지 |
| 더 즐거운가 | 선택 뒤 느낀 기대감·발견의 재미를 같은 척도로 평가하고 이유를 짧게 질문 |
| 현실적인가 | 왕복 기준·체류 시간·주차 미확인 상태를 정확하게 이해했는지 |
| 입력이 부담스럽지 않은가 | 추천 전 필수 조작 수, 모르는 표현에서 복구하는 시간, 설문처럼 느낀 지점 |
| 출발이 명확한가 | 샘플 후보 선택과 실제 내비 목적지 변경을 구별하고 승인할 수 있는지 |

분위기 문구가 더 좋다는 평가만으로 차별성을 입증했다고 판단하지 않습니다. 구체적인 체험 이해와 선택 부담이 개선되는지, 정보 오해나 조작 수가 늘지 않는지를 함께 봅니다. 같은 결과를 감성적으로 포장했을 뿐이거나 설문 부담이 커지면 흐름을 다시 줄입니다. 이 비교는 계획이며 사용자 모집·실행·효과 측정은 아직 하지 않았습니다.
