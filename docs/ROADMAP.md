# 제출 이후 개선 계획

내키면은 목적지를 정하지 않은 순간에 상황·기분·동행 조건에 맞는 외출과 여행을 고르는 차량용 앱입니다. 제출한 0.2 APK와 서명 신청서는 보존하고 후속 버전은 별도 산출물로 관리합니다. 픽업·분리 외출·재합류로 제품 목적을 바꾸지 않습니다.

## v0.3 현재 위치로 등록 장소 살펴보기

현재 구현 목표는 **실제 위치 기능의 첫 버전**입니다. 전국 실시간 검색이나 완성 제품을 뜻하지 않습니다. 서울시 공원 자료에서 검토한 서울숲·월드컵공원·서울대공원 세 곳을 기기에 포함하고, 유효한 전경 위치와 공원 대표점 사이의 직선거리 50km 이내 후보를 보여줍니다. 장소의 출처·검토일, 실제 장소와 샘플, 대표점과 차량 입구를 구분합니다.

| 우선 작업 | 완료로 판단할 조건 |
| --- | --- |
| 명시적 전경 위치 사용 | 사용자가 선택할 때 권한 요청. 위치가 없어도 앱이 종료되지 않고 현재 상태와 다음 행동을 설명 |
| 위치 품질 | 단조 시계로 신선도 검사, 실제 정확도와 권한 수준 구분, 오래됨·오차 큼·미래 시각·잘못된 좌표 거절 |
| 제한된 실제 카탈로그 | 등록된 세 공원의 출처·검토일·대표점 성격 표시. 미지원 지역을 서울 샘플로 자동 치환하지 않음 |
| 거리와 시간의 구분 | 직선거리를 도로거리·이동시간으로 바꾸지 않음. 이동시간이 없으면 왕복 가능·체류 시간을 산출하지 않음 |
| 실패 복구 | 거절·권한 차단·위치 꺼짐·취득 실패·위치 만료·결과 없음에서 반복 팝업 없이 재시도나 명시적 샘플 선택 가능 |
| 주행·정차 | 정차 시 위치·권한 설정 및 비교. 주행 시 한 곳 요약·명시적 목적지 확인. 상태 미확인이나 오래된 요청으로 경로 변경하지 않음 |
| 개인 정보 | 실제 위치·입력 문구를 로그·분석·영속 기록·Gleo 응답에 기본 저장하지 않음. 전경 종료·권한 철회 시 구독과 지연 응답 정리 |

반복 실행의 위치 사용은 선택형 선호로 다룹니다. 사용자가 정차 중 명시적으로 켠 ‘앱을 열 때 내 위치 사용’ 여부만 저장하며, 위치값·이동 이력·문장 원문은 저장하지 않습니다. 매 실행 시 현재 권한을 확인하고 D에서 새 권한창을 띄우지 않습니다. 샘플 모드나 OFF 선택은 이후 실행에서도 존중합니다. 이 동작의 실제 기기 검증은 최종 실행 기록에 남깁니다.

현재 코드의 위치 기준은 최대 120초와 수평 정확도 5,000m입니다. 이는 초기 구현값이며 공식 보장이나 고객 검증 결과가 아닙니다. 경계값 시험과 실제 정확도에 맞는 거리 표시가 필요합니다. 구현·시험 결과는 README와 테스트 기록을 기준으로 확인합니다.

실시간 영업·혼잡·주차 빈자리는 각각 다른 데이터 문제입니다. 키가 없거나 지역·시각이 맞지 않는 값을 다른 지역에 적용하지 않습니다. 계정·광고·예약·수집형 보상·자동 이용 분석은 이번 v0.3의 필수 기능으로 추가하지 않습니다.

## 실제 이용 가치 검증

위치 취득이나 테스트 통과만으로 반복 사용 가치가 입증되지는 않습니다. 같은 장소·조건에서 일반 목록과 내키면의 활동 제안을 비교해 선택까지의 조작, 선택 이유, 대표점·직선거리·시간 미확인 이해, 내비 인계 후 다시 검색한 수고를 관찰합니다. 위치가 없거나 등록 지역 밖일 때에도 사용자가 다음 행동을 알아야 합니다. 이용 통계를 기본 수집하기 전에 작은 과업 관찰로 필요성을 확인합니다.

아고라의 실제 의견·반론과 이번 변경에 반영한 내용은 [개선 검토 기록](IMPROVEMENT_REVIEW.md)에 정리합니다. 모델의 합의는 사용자 효과나 시장 우위를 증명하지 않습니다.
