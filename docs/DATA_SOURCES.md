# 실제 장소 데이터와 확인 범위

0.3은 위치를 받아 가까운 **등록 장소**를 찾는 첫 개발 버전이다. 전국의 영업 중인 장소를 실시간 검색하는 서비스가 아니다. 서버 인증키 없이 실행할 수 있도록 아래 검토한 세 장소를 앱에 포함했다. 실행 중 공식 API를 호출하거나 사용자 위치를 외부에 보내지 않는다.

[서울숲 운영기관 안내](https://parks.seoul.go.kr/park/detailView.do?pIdx=5), [서울 공원 안내](https://parks.seoul.go.kr/content.do?key=2604070017)도 함께 확인했다.

명칭·주소·대표 좌표와 주차 시설 안내만 사용한다. 설명·활동 제안은 앱의 편집 내용이다. 이용허락은 데이터셋에 기재된 **공공누리 제1유형, 출처표시**를 따른다. 운영기관의 사진·로고는 복제하지 않았다. 앱 화면의 출처와 이 문서를 함께 유지한다.

## 그대로 단정하지 않는 정보

- 대표 좌표는 공원 중심이나 등록 지점이며 **차량 출입구·주차장 진입점이 아니다**. 사용자가 내비에서 접근 경로를 확인하도록 장소 상세와 출발 확인에서 안내한다.
- 주차 시설의 존재와 빈자리·이용 요금·차종 제한은 별개다. 빈자리는 항상 미확인이다.
- 현재 위치에서 대표 좌표까지의 **직선거리**만 계산한다. 도로 이동 거리·소요시간·도착시각·왕복 가능 여부를 추정하지 않는다.
- 실내 피신 조건에 맞는 장소는 아직 없다. 실외 공원을 실내 장소로 추천하지 않는다.
- 운영시간·입장권·행사·혼잡·날씨는 실시간 확인하지 않는다. 원자료의 오래된 시간표·요금은 앱에 복사하지 않았다.
- 남산공원은 승용차 통행 제한, 길동생태공원은 사전 예약 조건이 있어 이번 즉흥 방문 후보에서 제외했다.

## 위치와 추천 규칙

사용자가 현재 위치 사용을 선택한 뒤에만 전경 위치 권한을 요청한다. 대략적 위치도 지원하며 정확도 차이를 표시한다. 2분을 넘긴 위치, 미래 시각, 유효하지 않은 좌표·정확도, 5 km를 넘는 오차는 추천 기준으로 쓰지 않는다. 위치와 입력 문장은 저장·전송·분석하지 않는다. 명시적으로 허용한 세션에서는 전경에서 45초마다 위치를 갱신하며, 주행 중 센서 갱신과 권한 팝업은 구별한다. 선택형 자동 시작 설정 Boolean만 기억할 수 있다. 에뮬레이터나 모의 위치 신호는 실차 GPS 검증과 구분한다.

등록 장소 중 직선 반경 50 km 안에 있는 곳만 남긴다. 5 km 거리 구간을 우선하고, 같은 구간 안에서 선택한 기분의 편집 우선순위와 직선거리로 정렬한다. 이는 도로 접근성·혼잡 기반 추천이 아니다. 실제 장소의 이동 시간이 없으면 제한 시간을 골라도 후보에 `이동 시간 확인 필요`를 표시하며 체류 시간을 만들어 내지 않는다.

실제 위치가 없거나 등록 범위 밖이면 빈 상태와 다시 시도하기를 보여 준다. 서울 샘플로 자동 대체하지 않는다. 기존 0.2 자료는 사용자가 `샘플 둘러보기`를 직접 선택한 경우에만 별도로 사용한다.

## 다음 데이터 연동

실제 차량 진입점, 실내 후보, 영업 일정, 이동 시간, 주차 현황을 우선 확장한다. 각 공급자마다 자료 시각·지역 범위·보관 허용기간·실패 상태를 따로 기록해야 한다. API 키를 얻는 것과 전국 정보가 확보되는 것은 다르다. 예를 들어 [서울시 실시간 도시데이터](https://www.data.go.kr/data/15146211/openapi.do)는 지정된 지역 범위의 인구·교통·주차 등 자료를 제공하므로, 그 지역 혼잡을 개별 매장의 혼잡으로 표시하면 안 된다.
