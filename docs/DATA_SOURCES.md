# 실제 장소 데이터와 확인 범위

## 0.4 카탈로그: 공원 3곳과 실내 기관 2곳

0.4는 서울·과천의 아래 **등록 장소 5곳**을 사용한다. 전국 장소 검색이나 현재 영업 중인 장소의 실시간 목록이 아니다. 실행 중 사용자 위치로 직선 반경 50km 안의 등록 장소를 찾으며, 공식 자료 API나 외부 지도에 사용자 위치를 전송하지 않는다. 일치하는 등록 장소가 없으면 빈 결과를 보여 주고, 서울 샘플로 자동 대체하지 않는다.

공원 3곳의 좌표·주소는 [서울특별시 주요 공원현황](https://data.seoul.go.kr/dataList/OA-394/A/1/datasetView.do)의 `SearchParkInfoService` 공개 예제 SN 3·4·5에서 **2026-11-16** 확인한 값을 유지했다. 당시 데이터셋 표시 갱신일은 2026-09-23이었다. 공원 내부 활동 지점의 운영기관 안내는 **2026-11-21** 다시 확인했다. 자료 조회일은 영업·주차 현황의 실시간 갱신 시각이 아니다.

서울역사박물관은 [운영기관 오시는길](https://museum.seoul.go.kr/chd/watch/watchGuideMap.jsp?tr_code=sweb)의 주소와 공식 연결 [지도](https://maps.app.goo.gl/n362YJAy8Z5461qX6)를 **2026-11-21** 확인했다. 연결된 지도 URL의 장소 마커 값 `!3d37.5704616!4d126.9705126`을 사용하며, 지도 화면 중심인 `@...` 값이나 주차장 출입구로 바꾸어 해석하지 않는다.

국립과천과학관은 [운영기관](https://www.sciencecenter.go.kr/gnsm/)의 주소와 [한국관광공사 열린관광 기관 상세](https://access.visitkorea.or.kr/ms/detail.do?cotId=d1f83bef-8fe6-4b8e-9c9f-36e1b2b6d20f)를 **2026-11-21** 확인했다. 관광공사 페이지 표시 수정일은 2026-11-10이며, 공개 HTML의 `findingAway` 인수와 `locationX`/`locationY`로 만든 지도 마커가 위 좌표로 일치했다. 과학관 안의 별도 기상 관측지점 좌표는 시설 대표 좌표로 사용하지 않았다.

모든 좌표는 **장소 대표점**이다. 차량 출입구, 주차장 입구, 실내 전시실이나 공원 내부 지점의 좌표로 검증된 값이 아니다. 내부 지점을 이어 보는 활동을 선택해도 내비게이션에는 기존 장소 대표점 한 곳만 전달하며, 경유지를 자동 추가하지 않는다.

## 0.4 장소별 활동 지점

`VisitPoint`는 이름·운영기관 자료 링크·확인일·출입 주의사항만 보관한다. 내부 지점의 위경도나 실제 이동 경로를 만들어 넣지 않았다. 아래 지점의 존재와 성격은 공식 자료를 확인했지만, 제안한 행동과 조합은 앱의 편집 내용이다. 운영기관의 추천 코스나 검증된 소요시간으로 표시하지 않는다.

국립과천과학관은 [과학탐구관 개선 공사 안내](https://www.sciencecenter.go.kr/gnsm/intro/notice/d/4162)에 2026-08-24~11-23 예정 휴관이 기재되어 있었다. 과학탐구관, 개관 일정 공지가 바뀌는 첨단기술관, 별도 예약형 체험·천문 프로그램은 이번 활동 조합에 포함하지 않았다. 예정일이 지났다는 이유로 자동으로 개방 상태를 바꾸지도 않는다. 과학관의 스마트 관람안내 QR 서비스 중단 공지도 확인했으며 QR 이용을 활동의 필수 단계로 넣지 않았다.

서울숲 거울연못은 수경시설의 계절 운영 영향을 받는다. [운영기관의 과거 수경시설 종료 공지](https://parks.seoul.go.kr/story/news/detailView.do?bIdx=3624&key=2604070028)를 참고해 물에 비친 풍경이나 현재 물이 차 있는 상태를 보장하지 않는다. 야외탁자·데크·잔디밭의 빈자리, 그늘, 혼잡도, 행사 중 이용 가능 여부도 확인하지 않았다.

## 시간과 기분이 활동을 바꾸는 방식

선택한 시간의 뜻은 기존과 같이 **사용자에게 남은 시간**이다. 입력값을 공식 현장 소요시간으로 바꾸지 않는다. 실제 장소의 이동·주차·현장 접근·왕복 시간이 없으므로 `stayMinutes`와 `overheadMinutes`를 만들지 않으며, 제한 시간을 골랐을 때는 계속 `TRAVEL_ESTIMATE_NEEDED` 상태를 유지한다.

- 30분 이하: 같은 지점에서도 한 대상이나 가까운 한 구간만 보는 활동을 고른다.
- 45분을 포함한 다른 제한 시간: 한 지점에서 조금 더 살펴보는 활동으로 바꾼다. 시간 안에 도착하거나 돌아올 수 있다는 보장은 아니다.
- 시간 미정: 한 지점에서 시작하고, 더 둘러볼지는 현장에서 선택한다.
- 명시적 제한 없음: 확인된 내부 지점 1~2곳을 선택적으로 이어 본다. 쉬기 목적은 한 곳에 머무르는 선택을 유지한다. 지점 간 접근로와 개방 여부는 별도로 확인해야 한다.

예를 들어 서울숲의 새로움 활동은 30분에서 ‘군마상에서 말 한 마리의 자세만 살펴보기’, 45분에서 ‘군마상을 앞과 옆에서 보며 말의 자세 비교하기’로 달라진다. 제한 없음에서만 거울연못을 선택적으로 덧붙인다. 서울역사박물관은 같은 시간 선택에서도 서울 모형의 동네 찾기와 상설 4존의 도시 변화 비교 등, 선택한 기분에 따라 다른 관람 행동을 고른다. 감정 진단이나 회복 효과를 주장하지 않는다.

`SceneRecommender.recommend(..., limit = Int.MAX_VALUE)`는 필터를 통과한 전체 후보를 제공한다. 기본 비교 결과는 기존처럼 최대 3곳이다. 전체 후보를 요청해도 중복 장소, 실내 조건, 위치 범위, 검증되지 않은 이동 시간에 관한 규칙은 그대로 유지한다. `SHELTER`는 실제 `indoor=true`인 독립 기관 두 곳만 통과시키며, 실외 공원의 내부 시설을 임의로 실내 후보로 바꾸지 않는다.

## 그대로 미확인인 정보

- 실제 도로 이동시간, 도착시각, 왕복 가능 여부, 주차 후 접근 시간은 없다. 계산하는 것은 현재 위치와 대표점 사이의 직선거리다.
- 주차 시설 존재와 주차 빈자리·요금·차종 제한·진입점은 다르다. 빈자리는 항상 미확인이고, 서울역사박물관의 주차 시설·이용 조건도 이번 카탈로그에서는 미확인으로 둔다.
- 운영시간, 입장료, 예약 필요 여부, 전시 교체, 출입 통제, 장치 가동은 실시간 조회하지 않는다. 앱에 ‘지금 운영 중’이나 입장 보장을 표시하지 않는다.
- 실내 기관도 비를 맞지 않고 주차장에서 전시실까지 이동할 수 있다는 보장은 없다.
- 공원·기관의 사진, 로고, 전시물 이미지를 복제하지 않았다. 공원 원자료는 데이터셋의 공공누리 제1유형 출처표시 조건을 따른다. 이 조건을 다른 운영기관 웹사이트나 외부 지도 전체에 적용된 이용허락으로 확대 해석하지 않는다. 새 기관은 명칭·주소·대표점 등 사실 정보와 출처 링크만 사용한다.

## 0.3 기록과 위치 처리의 유지 범위

0.3.0-preview에는 서울숲·월드컵공원·서울대공원 **3곳만** 들어 있었다. 이 문서의 5곳·장소별 내부 지점·실내 후보·시간별 활동 변화는 **0.4 변경**이며, 과거 제출본이나 0.3의 검증 결과에 소급해 포함하지 않는다. 0.2 샘플은 사용자가 샘플 모드를 명시적으로 선택한 경우에만 사용한다.

위치는 메모리에서만 다루고, 명시적으로 허용한 전경 세션의 갱신과 권한·신선도 검사를 유지한다. 2분을 넘긴 위치, 미래 시각, 유효하지 않은 좌표·정확도, 5km를 넘는 오차는 추천 기준으로 사용하지 않는다. 에뮬레이터와 모의 위치는 실차 측정과 구분한다. 선택형 자동 시작 Boolean만 저장할 수 있으며, 좌표·입력 문장·방문 이력은 저장하지 않는다.

앞으로 전국 데이터, 차량 진입점, 운영 상태, 교통·주차 자료를 연결할 때는 공급자별 지역·갱신 시각·이용 조건·누락 상태를 따로 확인해야 한다. 예컨대 [서울시 실시간 도시데이터](https://www.data.go.kr/data/15146211/openapi.do)의 지역 혼잡을 개별 기관이나 전시실의 혼잡으로 표시해서는 안 된다.
